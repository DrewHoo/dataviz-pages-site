# dataviz-pages-site

A private [Claude Code](https://claude.com/claude-code) skill. Build, scaffold, or troubleshoot a
data-viz project that deploys to GitHub Pages under `drewhoover.com/<repo-slug>/`. Covers the full
stack — repo + Vite base-path config, Actions deploy and scheduled data refreshes, build-time data
fetching, shareable URL state, mobile-first responsive design, OG/Twitter meta tags + favicon +
preview image generation, lazy-loaded analytics, common date-handling traps, and registering the
project on the drewhoover.com index.

See [`SKILL.md`](SKILL.md) and the deep-dives in [`references/`](references/).

## Install

Clone into your Claude Code skills directory:

```sh
git clone git@github.com:DrewHoo/dataviz-pages-site.git ~/.claude/skills/dataviz-pages-site
```
